## The finding

The cause is the head's product shape, not a different model path. The evidence, on `c1_000` (P 22), all logits compared bit for bit:
- the scratch diagnostic `ref_diag_l2k.py` (`b7e11c4a...`);
- its output `results/r4412/ref-diag/l2k-c1_000.json` (`a136faa9...`) on the measurement host.

| Comparison | Bits that differ |
|---|---|
| `model(x, use_cache=False).logits[0, P-1]` against the control's saved all-rows row | 0 (the reference is deterministic) |
| `model(x, use_cache=True, logits_to_keep=1)`, the call generate() makes, against generate's step 0 | 0 |
| `model(x, use_cache=False, logits_to_keep=1)` against generate's step 0, and against the line above | 0 |
| the same against the all-rows row | 144,505 of 201,024, at most `1.717e-05` |

transformers `6173a2f6`'s `generate()` passes `logits_to_keep = 1` (generation/utils.py, by the forward's signature), and Inkling2LoopForCausalLM slices the last hidden state before `lm_head`. So generate's head is a 1-row product, and PREREG 0.1's baseline is row P-1 of a P-row product. The CPU BLAS rounds the two shapes differently. Every layer and the cache path give the same bits.

## The corrections

1. **The step-0 check (PREREG 0.1 and 4.2(3)) compares like with like.** generate's step-0 logits are compared with the `use_cache=False` forward's row computed with the same head shape: `model(x, use_cache=False, logits_to_keep=1)`. Bit-equality stays the bar. The all-rows row is compared as information too, and its bit count and largest difference are recorded. The control is RERUN under this check, with `tools/ref_generate.py` version 2, committed with this erratum. The void run's results stay unmerged.
2. **The teacher-forced method stays as pre-registered:** one `use_cache=False` forward over `s`, all rows. Its rows are the multi-row head product, while the reference's own generation computes a 1-row head at every step. So the teacher-forced argmax can differ from the generation's only where a row's top-1 minus top-2 margin is below the head-shape rounding.
   - Every generated position whose reference margin is below `1e-4` is flagged as head-shape sensitive. The bound is about 6x the largest rounding measured, `1.717e-05`, and is fixed here, before any verdict exists.
   - The flags are reported per prompt and per engine, beside every Claim 1 table, with whether each verdict depends on a flagged position.
   - A flag changes no verdict.
   - `tools/verify_tf.py` version 2 does this, committed with this erratum.
3. **Nothing else changes:** no setting, prompt, metric, interval method, decision rule or claim wording. The control's verdict check (PREREG 0.1) and 4.2(3)'s other conditions stand as written.
