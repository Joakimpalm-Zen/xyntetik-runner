- **CUDA's slow kernel-load notice now states only the measured wait instead of claiming an undetected JIT compile** (R6.130).
  - `module_load_noted()` in `src/cuda.c` used a 2-second timer (`plat_slow_note_begin`) to print `"gpu: compiling the GPU kernels for this card and driver; ... later loads take them from the driver's cache"` without checking whether a compile occurred, which fired falsely on a slow cached load under heavy host contention. It now prints `"gpu: loading the GPU kernels is taking longer than 2 s; still waiting on the CUDA driver"` and renames `g_jit_noted` to `g_mod_slow_noted`.
  - POSIX `plat_slow_note_begin()` in `src/compat.c` now waits on `CLOCK_MONOTONIC` (`pthread_condattr_setclock` on Linux/POSIX, `pthread_cond_timedwait_relative_np` on macOS) instead of `CLOCK_REALTIME`, so wall-clock/NTP jumps cannot fire or delay the note.
  - `tests/test_slow_note.c` guards the CUDA slow-note wording against unverified compile or cache claims.
