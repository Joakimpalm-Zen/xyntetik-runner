- **`--info fit` answers a file whose agent profile the loader refuses** (R6.68.50): the load checked a `gridcore.agent.*` profile before it made its plan, and the fit only asked the plan, so a file requiring an agent feature this build lacks, requiring MTP consumption, or carrying a malformed schema digest was priced while its load refused it. The check is now the plan's first step, so the fit answers such a file `verdict WILL NOT LOAD` with the load's own words and exit status 1. A file without a profile, or with a valid one, is answered as before.
