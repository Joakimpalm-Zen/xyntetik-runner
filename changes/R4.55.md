- **`--type-plan` gains an exact `"name"` rule and `--type-plan-show`, and warns about the substring trap** (R4.55,
  with R6.129).
  - A plan rule is now `{"match": S}`, which applies to every tensor whose name holds S, as before, or
    `{"name": N}`, which applies to the one tensor named N. The first rule that applies wins, whichever kind it is.
    A rule with both keys or neither is refused, and a key no rule reads is named once in a warning.
    - Existing plans mean what they did. An older runner refuses a `"name"` rule rather than reading it as a
      substring.
  - `-m FILE --type-plan PLAN --type-plan-show` writes nothing. It prints a JSON line per tensor (the rule that
    applied, the type asked, the type the rewrite would write, and why), then one per rule (the tensors it took,
    its warning) and one for the default.
    - The listing comes from the rewrite's own decision. On the tiny files, its "written" types equal those of the
      file a real run writes, for every tensor, with a declined rule and width fallbacks.
  - Every run now warns, and `--type-plan-strict` refuses:
    - when a `"match"` is the whole role of a tensor yet also takes tensors of another role. `"output.weight"`
      takes every `blk.N.attn_output.weight`; the message names the fix.
    - when a `"name"` names no tensor in the file.
  - A `"match"` that takes nothing is warned about only, so a generic plan still works under strict on a smaller
    file.
  - The case that found it: the method scout's hand-written stock map took 32 `attn_output` tensors with its
    `output.weight` rule. `tests/test_type_plan_exact.py` holds that map against OLMo 3's 355 tensor names: rule 0
    takes 33 tensors and warns, and the same rule as `"name"` takes 1. Its 7 tests failed on main.
  - R6.129: `.gitignore` lists the nine outputs `make test` left untracked on macOS. Those are `test-full-grad`,
    `test-gpu-id-bounds.out`, `test-inkling2-kvq8` (and `.out`), `test-inkling2-requant` (and `.out`),
    `test-metal-lfm2.out`, `test-mv-tol-missing.out` and `test-slow-note`, with each binary's `.exe` for Windows.
  - Known limits:
    - `derive` still writes `"match"` guard rules, so its plans stay loadable by older runners.
    - A `.gitignore` entry is still added by hand when a test target is; nothing checks it.
