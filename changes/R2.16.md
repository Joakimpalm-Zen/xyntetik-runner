- **Apertus: a turn ends where the model closes a tool call** (R2.16). The publisher's generation settings end a reply at `<|tools_suffix|>` as well as at `<|assistant_end|>`; the GGUF files declare only the second, and Runner followed the files. On a turn with no tools declared, the 2509 model sometimes ends its reply with a `display_answers` call, and Runner then let it run on and write an invented result for that call (`["Answers displayed"]`) into the content. Runner now stops at `<|tools_suffix|>` for this family, as the publisher's own stack does.
  - **Unchanged:** turns with tools declared, which are constrained to the call document and never reach that token; every other family, which does not stop on this token.
  - **Still there:** the call itself, which the model writes before the stop, remains in the content of such a reply.
