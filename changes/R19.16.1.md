- Context-overflow refusals name both token counts (R19.16.1):
  - HTTP 400 `context_length_exceeded` errors on `/v1/completions`, `/v1/chat/completions`, `/v1/messages`, and `/v1/responses` now include `(<N> tokens; the context holds <C>)` in the error message while keeping the existing error `code` and `param` unchanged; `/v1/embeddings` and `/v1/rerank` (`/v1/decide`) include the same counts on their context-overflow 400s.
  - Importing a KV snapshot whose token count does not fit this server's context window now returns HTTP 409 `snapshot_model_mismatch` naming both lengths instead of `snapshot_corrupt`.
