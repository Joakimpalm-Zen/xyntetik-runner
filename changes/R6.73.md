- **PR E: test gates that tell the machine from the engine** (PR E).
  - **test-mlock no longer fails when the OS refuses to wire under memory pressure** (R6.73). macOS returns EAGAIN for a lock it cannot make resident when the machine is short of memory, far below its wire limit, and the gate read that as the engine locking wrongly (it failed once in a full gate run on an 8 GB Mac and passed 6 of 6 alone). A failed lifecycle now runs again, up to three times a second apart; a wrong lock fails every time and the test never passes without having locked. When all three fail and the machine cannot wire the fixture's size, the failure says the machine is short of wireable memory.
  - **Copy-from-context decoding stays opt-in on the CPU, measured** (R3.65). `--draft-lookup` gives plain decoding's tokens, but on the CPU it is 1.15x on an edit prompt and 11.8% slower on prose, short of the 1.2x and 2% bars, so the default does not change. The record is `docs/compat-reports/r3.65-cpu-lookup-default-2026-11-14/`.
