- Model rewrites (`--quantize`, `--merge-lora`, `--context-surgery`) and KV snapshots now publish their output and provenance record together as a pair under a sibling `<out>.publish.lock` file lock (`flock` on POSIX, `LockFileEx` on Windows). Any existing record is backed up first so a failed replace atomically restores the previous pair and preserves the new rewrite temporary, non-`EINTR` lock errors refuse cleanly (with one warning on file systems that do not support locking), and crashes in the narrow window between record and output replacement are detected as hash mismatches by `--lineage` and snapshot loading.
