- **`make cross-riscv64` builds again** (R6.86 follow-up). `src/instances.c` calls `fcntl` to keep the tray lock out of child processes (R9.5) but did not include `<fcntl.h>`, which POSIX declares it in. glibc's and macOS's `<sys/file.h>` bring it along, and musl's does not, so the riscv64 musl cross build stopped at "call to undeclared function 'fcntl'". The file now includes it. No CI job runs `cross-riscv64`, which is why nobody saw it.
