- **Stability pass follow-ups** (R6.68.18, R6.68.20): `run_completion` built a constrained turn's closure report, and freed the turn's document, before the final flush of the reasoning splitter. A partial tag the splitter still held was then appended to the freed document, which allocated a buffer nothing released (one leak per such turn, found by the Linux lane's run of the whole suite under AddressSanitizer), and the report was computed without those bytes. The report is now built once the turn's last byte is in the document, and the document is freed on every exit. The serve soak compares swap-phase memory per resident model (the first Windows run reported two models' size difference as growth) and reads the macOS footprint where the server reports it.
