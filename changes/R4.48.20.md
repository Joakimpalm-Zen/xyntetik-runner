- **Inkling 2 Mini: multi-column NVFP4 product** (R4.48.20, work in progress).
  - Pre-kernel tests (`tests/test_nvfp4_dot.c` cases 5-7, `tests/test_dot_route.c` `ratio(T_NVFP4, "NVFP4")`, and observed `vec_dot_multi_fallbacks()` counter in `src/quants.h`/`src/quants.c`): requires `vec_dot_multi(T_NVFP4)` over `nc = 2..8` columns to take the per-column fallback for `0` columns (red before the kernel lands), guards multi-column `<= 1.5x` per-column loop throughput, and locks byte-equality to `vec_dot` across block widths (`64..6144`), non-contiguous column strides, output guard sentinels, `nc > VEC_DOT_MULTI_MAX`, all 256 UE4M3 scales x 16 E2M1 codes, alternating-sign sub-block cancellation, and double-precision error `<= 1e-5`.
  - **Design note on AVX-512:** sharing one 16-lane `__m512` kernel between single-column `vec_dot` and multi-column `vec_dot_multi` on AVX-512 builds keeps `-b 1`, `-b 8`, and `-b 64` byte-identical, and changes single-column NVFP4 `vec_dot` bits relative to the AVX2 8-lane kernel (expected under 'speed first'; the fast route re-qualifies later on the final build).
