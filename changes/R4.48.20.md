- **Inkling 2 Mini: fast CPU route Tier A + Tier B speedups** (R4.48.20).
  - **Tier B — vector attention core (`src/inkling2.c`):** vectorises the fast route's attention core (`ink2_attn_core_fast_range`) with SIMD `ink2_dot_f32` (`8`-wide AVX2+FMA / `4`-wide NEON), SIMD softmax `exp` (`ink2_vexp8` / `ink2_vexp4`), `j`-outer tiled SIMD `V` accumulation, and `ink2_par` across `queries x heads` (threads split independent query-head pairs; the reference route keeps the serial order). **Expected under 'speed first': changes the fast route's output bits (re-qualifies later on the final build).**
  - **Tier B — vector SwiGLU (`src/inkling2.c`):** vectorises `ink2_swiglu_range` using SIMD `exp` and `tanh` (`ink2_vexp8`/`ink2_vtanh8` on AVX2+FMA; `ink2_vexp4`/`ink2_vtanh4` on NEON) over 8-element blocks split via `ink2_par` (thread-invariant across `1`/`4`/`16` threads). **Changes the fast route's output bits (re-qualifies later on the final build).**
  - **Tier B — AVX-512 variants (`src/quants.c`):** under `#if defined(__AVX512F__)`, adds 16-lane AVX-512 kernels for `NVFP4` (`dot_nvfp4_avx512`, `dot_nvfp4_avx512_multi`, and `dq_nvfp4_avx2`'s `__AVX512F__` path), `BF16` (`dot_bf16_avx512`, `dot_bf16_avx512_multi`), and `Q8_0` (`dot_q8_0_avx512`, `dot_q8_0_avx512_multi`), with `nc = 2..8` unrolled in `vec_dot_multi`. Each pair shares one 16-lane kernel so `vec_dot` and `vec_dot_multi` stay byte-equal across `-b 1`, `-b 8`, and `-b 64`. **Changes the fast route's output bits on AVX-512 builds (re-qualifies later on the final build).**
  - **Parallel SwiGLU (`src/inkling2.c`):** parallelises `ink2_experts_fast`'s SoftcappedSwiGLU loop over active positions x feed-forward elements via `ink2_par` (work=32), keeping scalar `p_tanhf`/`p_expf` math unchanged so every row stays byte-identical to `0c60e1e8` at any thread count.
  - **Batched message gates (`src/inkling2.c`):** `ink2_message_step`'s fast path now runs the input/message unweighted norms in parallel over positions, batches `down_proj`, `forget_gate_proj`, and `message_gate_proj` across all `T` positions through `ink2_lin_rows` (`vec_dot_multi`), and runs the scalar `p_tanhf` gate combination in parallel over `[T][H]` via `ink2_par`. Every row stays byte-identical to `0c60e1e8`.
  - **Multi-column NVFP4 (`src/quants.c`):** `vec_dot_multi` dispatches `T_NVFP4` to `dot_nvfp4_neon_multi` (NEON) and `dot_nvfp4_avx2_multi` (AVX2+FMA, with compile-time unroll over `2..8` columns and split even/odd column loops inside the 16-YMM budget). Each 32-element half decodes once into registers and accumulates per column in `vec_dot`'s exact two-accumulator order, so `vec_dot_multi` is byte-equal to `vec_dot` (`tests/test_nvfp4_dot.c` case 5 goes green with `0` fallback columns; `tests/test_dot_route.c` measures `0.46x` of the per-column loop at 7 columns on arm64).
  - **Last-row-only prefill head (`src/inkling2.h`, `src/inkling2.c`, `src/inkling2_model.c`, `tests/test_inkling2_fast.c`, `tests/test_inkling2_hardening.py`):** `model_inkling2_forward` now skips `model.norm` and `ink2_head` on intermediate chunks and uses `INK2_LOGITS_LAST` on the final chunk when `!keep_all` and `RUNNER_INKLING2_ROWS` is unset (evaluating `ink2_head` for 1 row instead of `T`, or 0 rows when `!want_logits`), while `--score` (`keep_all`), row dumps, and `ink2_forward_chunk` continue computing every row byte-identically.
  - **CLI load line thread count (`src/main.c`, `tests/test_inkling2_hardening.py`, R4.48.18):** prints `model_inkling2_threads(&rt->m)` instead of `tpool_size(rt->m.tp)` (`0`, since `inkling2_loop` leaves `m->tp` NULL on CLI and takes the count inside `model_inkling2_forward`), with a hardening test on the tiny file at `-t 2` checking `| 2 threads |`.
  - **Fixture build fix (`Makefile`):** links `test-inkling2-fixture-bin` with `$(QUANTS_OBJ)` (needed since the fast route's `src/inkling2.c` calls `dequant_row`, `q8_quant_row`, `vec_dot`, and `vec_dot_multi`), and compiles/links all external-data-gated Inkling test binaries (`test-inkling2-fixture-bin`, `test-inkling2-provider-bin`, `test-inkling2-gguf-bin`, `inkling2-read-bin`) in `test-gates-core` (`make test`) so link regressions cannot pass unnoticed.
  - **Pre-kernel tests (`tests/test_nvfp4_dot.c` cases 5-7, `tests/test_dot_route.c` `ratio(T_NVFP4, "NVFP4")`, `vec_dot_multi_fallbacks()`):** requires `vec_dot_multi(T_NVFP4)` over `nc = 2..8` columns to take the per-column fallback for `0` columns, guards multi-column `<= 1.5x` per-column loop throughput, and locks byte-equality to `vec_dot` across block widths (`64..6144`), non-contiguous column strides, output guard sentinels, `nc > VEC_DOT_MULTI_MAX`, all 256 UE4M3 scales x 16 E2M1 codes, alternating-sign sub-block cancellation, and double-precision error `<= 1e-5`.
