- **Muse's native (atem) tool calls recover a cut-off argument of every JSON-spelled type as the forced close writes it** (R2.21).
  - Numbers already did (R2.19.1). Now an object, array or boolean parameter gets its fill too. A boolean with `const: true` comes back `true`, where it came back `false`. An array with `minItems` comes back with that many items, each its items' fill, where it came back `[]`. An object comes back with its required properties, where it came back `{}`. A parameter whose schema the compiler refuses now fails the call, where it came back as the literal.
  - When an allocation fails while a whole argument is parsed, the call now fails. Before, the argument was read as cut off and replaced by the recovered value (`10` in place of a valid `12`).
