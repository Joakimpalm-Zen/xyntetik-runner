- **The desktop tray on Linux** (R18.15). `runner --tray`, and a `--serve` or `-i` run at a terminal in a desktop
  session, put Runner's icon and menu in the desktop's tray: the instances live on the machine, stop, start the
  managed model, pick a model, launch at login and quit, as on macOS and Windows.
  - It is a StatusNotifierItem with a `com.canonical.dbusmenu` menu on the session bus. It was run live on Ubuntu's
    GNOME desktop with its AppIndicator extension. KDE Plasma, and XFCE or Cinnamon with their tray plugins, host the
    same protocol and were not run live.
  - libdbus-1 is loaded with `dlopen` when a tray starts, through Runner's own declarations, so the build needs no
    `-dev` package and the binary names no new library.
    - Without the library, a session bus, a display or a tray host, `--tray` ends with one line saying which is
      missing, and exit code 1. Every other command is unchanged.
    - A serve or chat run raises a tray only when a session bus, a display and a tray host are all there.
  - Launch at login writes `~/.config/autostart/xyntetik-runner-tray.desktop` (or under `$XDG_CONFIG_HOME`), with
    the binary's absolute path quoted. Turning it off removes the file.
  - Pick model uses the desktop's file chooser portal, then zenity or kdialog run without a shell. With none of the
    three, the row is disabled.
  - When the session bus goes away (a logout), the tray ends the way Quit ends it, stopping its managed server.
  - When the tray host goes away and stays gone for 30 s, the tray ends the same way, saying so on stderr. A shell
    restart inside the window only re-registers the item. Quit stops the server the tray started and only that one,
    so a `--serve` someone else started keeps running.
  - Menu ids are the rows' own and never reused, so a late click acts on the row it meant or on nothing.
  - `tests/test_tray_linux.c` runs the tray on a private session bus against a fake tray host. It checks:
    - registration;
    - the icon's ARGB32 bytes at five sizes;
    - the menu tree against the core's items;
    - a live click on the autostart row;
    - Quit;
    - no host and no bus;
    - the bus killed under a tray with a managed server.
  - The same test static-asserts Runner's libdbus declarations against the real `<dbus/dbus.h>`. CI checks that
    `runner` has no `DT_NEEDED` entry for libdbus, and runs the non-tray commands and `--tray` in a container
    without libdbus.
  - Known limit: the icon is drawn light for GNOME's dark top bar; it cannot follow the theme.
