- **A Phi-3 load with a context over the model's original one says what that costs** (R4.40). Phi-3.5 ships two LongRoPE factor sets. Runner, like llama.cpp, picks the long set when `-c` is over the original context (4,096) and applies it from the first token; the publisher's code applies it only to a sequence longer than that.
  - **Measured** on bartowski's Phi-3.5-mini-instruct Q8_0 against the publisher's checkpoint in float32, one window of 272 positions of a 4,096-token text: 0.0042 mean KLD at `-c 4096` and 0.2052 at `-c 8192` (llama.cpp: 0.0073 and 0.2071).
  - **What changes:** the load prints one warning line when the long factors are in use, naming the context that avoids it. Nothing changes in what the model computes, and the default context (4,096) never used the long factors.
  - **Not fixed here:** choosing the factor set per sequence, as the publisher's code does, is the item's second step.
