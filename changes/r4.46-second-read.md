- **`runner derive`: a verdict is never given without the interval it rests on.** A second read of R4.46 found one
  defect and two holes in its tests.
  - When the bar's interval could not be computed for rows that exist (an allocation failure), the missing interval
    read as "a result without rows" and the point estimate was used: a file that is "not decided" came out a pass.
    `derive` now stops with "no verdict is given without it", for the file and for a `--compare` file alike. The
    point estimate remains the fallback only for a reference result that has no per-position rows.
  - Rows that carry no KLD are refused too: a result with rows, none or only some of which can be resampled, gave a
    point verdict with no interval. Every row must carry its KLD, or `derive` stops.
  - Tests added that fail without the mechanism they guard: a compared file whose two point estimates pass while its
    interval crosses the bar reads "not decided" in the record and on the card; and `--info fit` on a split model
    gives the same report when every part is cut down to its header.
