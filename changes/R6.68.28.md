- **A file that names its sliding layers' rope base `rope.local.freq_base` now gets that base on every compiler** (R6.68.28, found in the full sweep): the loader read `rope.local.freq_base` and its fallback `rope.freq_base_swa` in one call, both spelled into the same key buffer, so the order a compiler evaluates arguments in chose the key. A clang build (every macOS build) read `rope.freq_base_swa` for both and roped the sliding layers at the wrong base whenever a file declared the two with different values. The reads are now made one at a time, and `test-rope-yarn` loads a fixture that declares 500 and 20000 and holds the sliding table to 500.
